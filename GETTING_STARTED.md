# Getting Started with SolFoundry 🏭

*Earn \$FNDRY by contributing to the SolFoundry ecosystem*

## What is SolFoundry?

SolFoundry is a community-driven bounty platform where contributors earn **\$FNDRY tokens** by completing tasks. Our AI-powered review ensures fast evaluation.

## Quick Start

### Step 1: Find a Bounty

Browse [Issues](https://github.com/SolFoundry/solfoundry/issues) with the `bounty` label:

| Tier | Type | Reward | Access |
|------|------|--------|--------|
| **T1** | Documentation, tutorials | 50K–150K \$FNDRY | Open to all |
| **T2** | SDK, features | 200K–400K \$FNDRY | Tier-gated |
| **T3** | Advanced development | 500K–1M \$FNDRY | Tier-gated |

### Step 2: Fork & Clone

Click the Fork button on GitHub, then:

```bash
git clone https://github.com/YOUR_USERNAME/solfoundry.git
cd solfoundry
git remote add upstream https://github.com/SolFoundry/solfoundry.git
```

### Step 3: Create a Branch

```bash
git checkout -b bounty/my-task
```

### Step 4: Complete the Task

Read acceptance criteria carefully. Keep PRs focused on one task.

### Step 5: Submit PR

```bash
git add .
git commit -m "feat: complete bounty task"
git push origin bounty/my-task
```

Open a PR on the original repo. AI review completes in 24-48h.

### Step 6: Earn Rewards

Approved submissions receive \$FNDRY tokens for governance, trading, or tier access.

## AI Review Process

1. Completeness check against acceptance criteria
2. Quality and standards verification  
3. Originality confirmation
4. Automatic reward distribution
