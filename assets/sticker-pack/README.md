# SolFoundry Sticker Pack

Submission for SolFoundry bounty #832: 10 transparent PNG stickers for Telegram, Discord, or print.

## Included

- 10 PNG files, 512x512, transparent background: `png/`
- 10 editable SVG source files: `svg/`
- Preview sheet: `preview-sheet.png`
- Checksums and metadata: `manifest.json`

## Design Notes

The pack uses SolFoundry's public brand cues from the repository: the official anvil/hammer logo motif, forge themes, automaton-style spark/cell accents, developer culture, $FNDRY, CI, PR review, bounties, and agent-first coordination. The visual system is consistent across all 10 stickers: bold circular sticker silhouette, high-contrast outline, readable top/bottom captions, and brand-adjacent colors from the README badges (`#00d4aa`, `#f59e0b`, `#6366f1`, `#fbbf24`) plus the official logo's green/purple energy cues.
